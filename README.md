# StudyFlow — Student Productivity Planner

A responsive web application that helps students organize their academic tasks, manage assignment deadlines, set priorities, and track their study progress.

## Features

- **Dashboard Overview:** View total, completed, pending, and overdue tasks.
- **Task Management:** Add, edit, delete, and mark tasks as completed.
- **Task Details:** Store task titles, subjects, descriptions, due dates, and priorities.
- **Search Tasks:** Find tasks by title, subject, or description.
- **Filter Tasks:** Filter tasks by completion status and priority.
- **Upcoming Deadlines:** View pending tasks sorted by due date.
- **Progress Tracking:** Monitor task completion using dynamic progress indicators.
- **Local Storage:** Save tasks in the browser and retain them after refreshing the page.
- **Responsive Design:** Access the planner on desktop, tablet, and mobile devices.

## Technologies Used

- HTML5 — Page structure
- CSS3 — Styling and responsive layouts
- JavaScript — Application logic and interactive features
- Browser Local Storage — Client-side data persistence

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension for VS Code (recommended)



## How to Use

1. Open the dashboard to view your task statistics and study progress.
2. Click **Add new task** to create a task.
3. Enter the title, subject, description, due date, and priority.
4. Save the task to add it to your task list.
5. Use the search bar and filters to find specific tasks.
6. Mark tasks as completed when you finish them.
7. Edit or delete tasks whenever necessary.
8. Open the Calendar section to review upcoming deadlines.
